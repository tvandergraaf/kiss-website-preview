# Klantlogo's referentiebalk

Zet hier het logobestand per opdrachtgever. De build pakt het automatisch op;
staat het bestand er niet, dan toont de balk de naam als tekst.

Verwachte bestandsnamen (zie src/data/site.json > references.items):
- dpg-media.svg
- nationale-postcode-loterij.svg
- vriendenloterij.svg
- wijboeken.svg
- kinderboekerij.svg

Eisen: SVG (voorkeur) of PNG met transparante achtergrond, minimaal 80 px hoog
bij PNG (liefst 2x), horizontale variant, geen witte achterplaat, geen payoff.
De balk toont de logo's op 40 px hoogte in grijstinten; bij hover kleur.

Per merk moet publicatietoestemming voor logogebruik zijn vastgelegd (proof-gap B).
